# B站直播弹幕助手 | Bilibili Live Danmaku Helper

**一键 +1 复读、收藏弹幕、快捷发送、独轮车循环发送。让 B 站直播间互动更方便。**

一个免费、开源的 Chrome 浏览器扩展，专为哔哩哔哩（Bilibili）直播间设计。

*An open-source Chrome extension for Bilibili Live. One-click danmaku repetition, copying, favorites, quick replies, automatic message rotation, and fullscreen support.*

[下载安装](https://github.com/sinpangky/bililive-danmaku-plus-one/releases/latest) · [查看源码](https://github.com/sinpangky/bililive-danmaku-plus-one) · [隐私说明](PRIVACY.md)

> 适用平台：B站网页版直播间 `live.bilibili.com`  
> 当前版本：v0.0.3 · Chrome Manifest V3 · 简体中文界面

## 它能做什么？

看直播时，遇到想复读的弹幕，不必自己重新输入。

把鼠标放在弹幕上，就能直接操作。

- **一键 +1 / 复读弹幕**：悬停直播画面中的弹幕，点击 `+1` 即可发送相同内容。支持文字、Unicode Emoji 和 B 站表情。
- **复制与快捷回复**：直接复制弹幕，或者一键填入 `@发送者`，继续输入回复。
- **弹幕收藏夹**：收藏喜欢的弹幕，按直播间分类管理，随时重新发送。
- **独轮车 / 循环发送**：输入多行弹幕，按固定或随机间隔自动循环发送，支持次数、时长与长文本分段设置。
- **全屏也能操作**：支持直播间普通模式、网页全屏和播放器全屏。
- **侧边聊天栏快捷操作**：可选开启聊天栏中的 +1、复制、收藏和回复按钮。
- **快捷键与本地备份**：使用 `Alt+Q` 打开功能面板，支持数字键快捷发送收藏，并可导入、导出 JSON 数据。

## 安装教程

目前通过 GitHub Releases 提供安装包，不需要自行编译，也不需要安装 Tampermonkey。

1. 打开 [最新版本下载页面](https://github.com/sinpangky/bililive-danmaku-plus-one/releases/latest)。
2. 下载 `bililive-danmaku-plus-one-v0.0.3.zip`，解压到一个固定目录。
3. 在 Chrome 地址栏输入 `chrome://extensions`。
4. 开启右上角的 **开发者模式**。
5. 点击 **加载已解压的扩展程序**，选择解压后的插件目录。
6. 打开或刷新任意 [B站直播间](https://live.bilibili.com/)。

安装完成后，把鼠标移动到直播画面中的弹幕上，试试 `+1` 按钮。

**注意：** Chrome 无法直接加载 ZIP 文件。目前采用手动安装及更新方式，升级后需要在扩展管理页面重新加载插件。

## 常用操作

| 操作 | 功能 |
|---|---|
| 悬停滚动弹幕 | 显示 +1、复制、收藏、回复 |
| 点击 +1 | 复读当前弹幕 |
| 点击收藏 | 保存到当前直播间收藏夹 |
| 点击回复 | 在输入框中填入 @发送者 |
| `Alt+Q` | 打开或关闭功能面板 |
| 收藏面板中按 `1`–`9` | 发送对应的可见收藏 |
| `Esc` | 返回上级收藏列表或关闭面板 |
| `Alt+单击` | 弹幕识别失败时尝试直接复读（可关闭） |

更多功能与设置详见完整使用文档。

## 为什么选择这个插件？

**不仅能 +1，还能保存喜欢的弹幕。**

不同直播间的收藏分别管理，也可以搜索、排序、快捷发送和跨直播间添加。

**全屏状态下仍可复读和发送。**

文字及支持混排的表情通过 B 站官方弹幕接口发送，不需要先退出全屏，也不会覆盖输入框中尚未发送的草稿。

**支持常见的 B 站表情。**

不仅处理普通文本，还能识别 Unicode Emoji、B 站小表情以及部分直播间专属表情。专属表情的发送受账号权限限制。

**数据由自己保管。**

收藏默认保存在浏览器本地，可手动备份或授权同步到本地 JSON 文件。插件不包含广告、分析或跟踪服务，也不会向开发者服务器上传收藏。

## 常见问题

**Q：有没有可以在 B 站直播间一键复读弹幕的插件？**

有。本插件支持在直播画面中悬停弹幕，显示 `+1` 按钮，无需手动复制粘贴，也支持可选的侧边聊天栏操作。

**Q：能在 B 站直播间自动循环发送弹幕吗？**

可以。内置独轮车功能，支持多行文本循环发送、固定或随机间隔、发送次数和总时长设置。需要用户自行启动。

**Q：B站直播全屏可以发送弹幕吗？**

支持普通页面、网页全屏和播放器全屏。发送需要正常登录，并受到 B 站发言权限和接口限制。

**Q：收藏会跨设备自动同步吗？**

弹幕收藏默认保存在当前浏览器本地，不会自动跨设备同步。可以通过 JSON 文件导入、导出或授权的本地目录进行备份与迁移。

**Q：支持手机 B 站 App 或其他直播平台吗？**

不支持。目前仅支持电脑浏览器中的 `live.bilibili.com`，不支持 B 站手机客户端、斗鱼、虎牙或抖音。

**Q：是否支持绕过禁言或平台发送限制？**

不支持。独轮车与普通发送均受 B 站平台限制，请合理设置发送频率，避免影响其他观众或触发风控。
